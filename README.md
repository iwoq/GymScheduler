# GymScheduler
This project aims to retrieve your google calendar and preferences and recommend you a good time to go to the gym.
## The Problem
Trying to find a good time to go the gym has been difficult. As a college student the schedule can be very full.
## How it works
This program accepts preferences from a user and fetches their google calendar. They will then be given the best possible time to workout.
